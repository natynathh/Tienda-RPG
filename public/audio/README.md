# Audio de Lira

Sube aquí el archivo `lira-intro-01.mp3` generado con Adobe Firefly. El componente de introducción ya reproduce automáticamente esa ruta cuando la visitante pulsa «Escuchar a Lira» o el altavoz de la interfaz.

Los demás diálogos se mantienen en texto hasta tener otras grabaciones. La síntesis del navegador es opcional desde Ajustes de voz.

Se recomienda comprimir las grabaciones MP3 para que el prototipo cargue rápido.
